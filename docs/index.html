Evidence, not a universal guarantee.

These are original, synthetic-data CPU demonstrations. No pretrained model, GPU, API key or uploaded data is required. Reports contain fingerprints and explicit numeric metrics, not raw weights.

This release targets deterministic CPU eager training. It does not validate CUDA, distributed training, AMP, undeclared state or future steps. Your training callbacks are trusted executable code, not sandboxed.

To reproduce: install the source, then run python -m resumetrace demo --fault process-cache --json drift.json --html drift.html. The expected exit code is 1 because the checkpoint is intentionally wrong.
